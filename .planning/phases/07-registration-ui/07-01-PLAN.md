# Plan 07-01: Registration Form with College Autocomplete & URL Referral Capture

## Goal
Build the student registration form with college search autocomplete, inline Zod validation, URL `?ref=CODE` parameter detection, and API integration that seamlessly leads to the referral dashboard on success.

## Artifacts this phase produces
- `frontend/src/pages/RegistrationPage.tsx`
- `frontend/src/components/registration/registration-form.tsx`
- `frontend/src/hooks/useColleges.ts` — debounced college search
- `frontend/src/services/registration.service.ts` — API calls
- `frontend/src/types/registration.ts` — shared TypeScript types

## Tasks

<task id="07-01-01">
<title>Create registration service, types, and college search hook</title>
<action>
Create `frontend/src/types/registration.ts`:
```typescript
export interface College { id: string; name: string; city?: string; state?: string }
export interface RegistrationInput {
  fullName: string; email: string; phone?: string;
  collegeId: string; graduationYear: number;
  referralCode?: string; source?: string;
}
export interface RegistrationSuccess {
  id: string; fullName: string; referralCode: string; referralUrl: string;
}
```

Create `frontend/src/services/registration.service.ts`:
- `searchColleges(query: string): Promise<College[]>` — GET `/api/v1/colleges?search=${query}` → returns `data.items`
- `registerStudent(input: RegistrationInput): Promise<{ user: RegistrationSuccess }>` — POST `/api/v1/registrations`
- Import from `frontend/src/lib/api.ts` (axios instance)

Create `frontend/src/hooks/useColleges.ts`:
- `useColleges(query: string)` using TanStack Query `useQuery`:
  - `queryKey: ['colleges', query]`
  - `queryFn: () => searchColleges(query)`
  - `enabled: query.length >= 2`
  - `staleTime: 5 * 60 * 1000` (5 minutes — colleges don't change)
  - Returns `{ colleges, isLoading }` destructured from query result
</action>

<task id="07-01-02">
<title>Build registration form with React Hook Form, Zod validation, and college autocomplete</title>
<action>
Create `frontend/src/components/registration/registration-form.tsx`:

Form fields using React Hook Form + zodResolver:

Zod schema (client-side mirror of backend):
```typescript
const registrationSchema = z.object({
  fullName: z.string().min(2, 'Name must be at least 2 characters'),
  email: z.string().email('Enter a valid email address'),
  phone: z.string().regex(/^\+?[0-9]{10,15}$/, 'Enter valid phone number').optional().or(z.literal('')),
  collegeId: z.string().uuid('Please select a college from the list'),
  graduationYear: z.coerce.number().min(2024).max(2028),
  referralCode: z.string().optional(),
})
```

College field implementation:
- Controlled text input for college search (visual display name)
- Separate hidden field for `collegeId` (UUID)
- `useColleges(searchTerm)` hook for autocomplete results
- Dropdown list below input showing matching colleges
- On select: set `collegeId` via `setValue('collegeId', college.id)`, display `college.name` in input
- Close dropdown on outside click

URL referral code detection:
- `const [searchParams] = useSearchParams()`
- `const refCode = searchParams.get('ref')`
- If `refCode`: pre-fill hidden `referralCode` field with it
- Display chip/badge: "Referral code applied: {refCode}" if detected

Form submission:
- `handleSubmit` validates → calls `registerStudent(data)` → on success navigate to `/dashboard/${user.id}?code=${referralCode}`
- Loading state: disable form + show spinner in button
- Server error handling: display API error message inline (EMAIL_ALREADY_REGISTERED → "This email is already registered. Did you mean to view your dashboard?")
- Preserve valid field values on server error
</action>
