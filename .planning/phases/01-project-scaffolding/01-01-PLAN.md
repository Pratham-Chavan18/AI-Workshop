# Plan 01-01: Backend Monorepo + Express Server Setup

## Goal
Initialize the backend Node.js/Express/TypeScript application with production-grade middleware, health check endpoint, structured logging, and environment configuration.

## Artifacts this phase produces
- `backend/` directory (monorepo workspace)
- `backend/src/app.ts` — Express app factory
- `backend/src/server.ts` — HTTP server entry point
- `backend/src/middleware/logger.ts` — Pino request logger
- `backend/src/middleware/errorHandler.ts` — global error handler
- `backend/src/routes/health.ts` — GET /health route
- `backend/tsconfig.json`
- `backend/package.json`
- Root `package.json` with workspaces config

<task id="01-01-03">
<title>Create Express app factory with production middleware</title>
<action>
Create `backend/src/app.ts` exporting a configured Express application:
- Import and apply `helmet()` for security headers
- Apply `cors({ origin: process.env.CORS_ORIGIN || '*', credentials: true })`
- Apply `express.json({ limit: '10kb' })`
- Apply `express.urlencoded({ extended: true })`
- Apply pino-http logger middleware (skip health check route)
- Mount GET `/health` route returning `{ status: 'ok', timestamp: new Date().toISOString() }` with 200
- Apply global 404 handler returning `{ success: false, error: { code: 'NOT_FOUND', message: 'Route not found' } }`
- Apply global error handler middleware in `src/middleware/errorHandler.ts`
</action>

<task id="01-01-04">
<title>Create HTTP server entry point and environment config loader</title>
<action>
Create `backend/src/server.ts`:
- Import `dotenv/config` at top
- Import app from `./app`
- Read `PORT` from `process.env.PORT` defaulting to `4000`
- Start HTTP server with `app.listen(PORT)`
- Log startup message using pino: `{ msg: 'Server started', port: PORT, env: process.env.NODE_ENV }`
- Handle `SIGTERM` and `SIGINT` for graceful shutdown

Create `backend/.env.example`:
```
PORT=4000
DATABASE_URL=postgresql://user:password@localhost:5432/ai60?schema=public
CORS_ORIGIN=http://localhost:5173
ADMIN_API_KEY=your-secure-admin-key-here
NODE_ENV=development
```
</action>
