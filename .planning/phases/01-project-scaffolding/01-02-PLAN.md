# Plan 01-02: Frontend Vite + React + TypeScript + Tailwind Setup

## Goal
Initialize the frontend Vite React TypeScript application, configure Tailwind CSS with shadcn/ui theme foundation, and establish the project structure matching the `docs/design.md` component architecture.

## Artifacts this phase produces
- `frontend/` directory
- `frontend/vite.config.ts`
- `frontend/tailwind.config.ts` — with custom Meta design token extensions
- `frontend/src/styles/globals.css` — CSS variables and Tailwind base
- `frontend/src/lib/utils.ts` — `cn()` helper
- `frontend/src/lib/motion.ts` — shared Framer Motion variants
- `frontend/src/main.tsx` — React entry point
- `frontend/src/App.tsx` — root router component
- `frontend/components/ui/` — directory structure for shadcn primitives
