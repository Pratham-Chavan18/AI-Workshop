<action>
Create `backend/prisma/seed.ts`:
- Import `prisma` from `../src/lib/prisma`
- Import `COLLEGES` from `./colleges-data`

Seed function:
1. Upsert default campaign using `prisma.campaign.upsert` with `where: { slug: 'ai60-oct-2026' }`:
   - `name`: `'Build Your First AI Project in 60 Minutes'`
   - `slug`: `'ai60-oct-2026'`
   - `targetRegistrations`: `500`
   - `startsAt`: `new Date('2026-10-04T00:00:00.000Z')`
   - `endsAt`: `new Date('2026-10-11T23:59:59.000Z')`
   - `status`: `'active'`

2. Seed colleges using `prisma.college.upsert` for each entry in `COLLEGES` with `where: { nameNormalized }` to ensure idempotency. Log count of upserted colleges.

3. Seed default admin user using `prisma.adminUser.upsert` with `where: { email: 'admin@ai60.nxtwave.com' }`:
   - Hash password `Admin@ai60!` using bcryptjs with 12 rounds
   - `role`: `'operator'`

4. Log completion: `console.log('Seed complete', { campaign, colleges: count, adminEmail: 'admin@ai60.nxtwave.com' })`

Update `backend/package.json` to add:
- `"prisma": { "seed": "ts-node prisma/seed.ts" }`
- Add `bcryptjs` and `@types/bcryptjs` to dependencies
</action>
