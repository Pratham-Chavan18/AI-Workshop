# Plan 02-01: Prisma Schema, Entities & Database Migration

## Goal
Define the complete PostgreSQL database schema using Prisma ORM with all entities (Campaign, College, User, Referral, AdminUser), relations, unique constraints, and indexes. Execute the initial migration.

## Artifacts this phase produces
- `backend/prisma/schema.prisma` — complete data model
- `backend/prisma/migrations/YYYYMMDD_init/migration.sql` — initial SQL migration
- `backend/prisma/migrations/migration_lock.toml`
- `backend/src/lib/prisma.ts` — singleton Prisma client export

## Tasks

<task id="02-01-01">
<title>Create Prisma schema with all production entities</title>
<action>
Create `backend/prisma/schema.prisma`:

Generator and datasource:
- `generator client { provider = "prisma-client-js" }`
- `datasource db { provider = "postgresql"; url = env("DATABASE_URL") }`

Model `Campaign`:
- `id String @id @default(uuid())`
- `name String`
- `slug String @unique`
- `targetRegistrations Int @default(500)`
- `startsAt DateTime`
- `endsAt DateTime`
- `status String @default("active")` — values: active, paused, closed
- `createdAt DateTime @default(now())`
- `users User[]`
- `referrals Referral[]`

Model `College`:
- `id String @id @default(uuid())`
- `name String`
- `nameNormalized String @unique` — lowercase trimmed for dedup
- `city String?`
- `state String?`
- `createdAt DateTime @default(now())`
- `users User[]`
- `@@index([nameNormalized])`

Model `User`:
- `id String @id @default(uuid())`
- `campaignId String`
- `collegeId String`
- `fullName String`
- `email String`
- `emailNormalized String` — lowercase trimmed
- `phone String?`
- `phoneNormalized String?`
- `graduationYear Int`
- `referralCode String @unique`
- `referredByUserId String?`
- `source String @default("direct")` — whatsapp, direct, other
- `createdAt DateTime @default(now())`
- `campaign Campaign @relation(fields:[campaignId], references:[id])`
- `college College @relation(fields:[collegeId], references:[id])`
- `referredBy User? @relation("UserReferrals", fields:[referredByUserId], references:[id])`
- `referrals User[] @relation("UserReferrals")`
- `referralsMade Referral[] @relation("ReferrerReferrals")`
- `referralReceived Referral? @relation("ReferredReferrals")`
- `@@unique([campaignId, emailNormalized])`
- `@@index([campaignId])`
- `@@index([referralCode])`
- `@@index([collegeId])`
- `@@index([referredByUserId])`
- `@@index([createdAt])`

Model `Referral`:
- `id String @id @default(uuid())`
- `campaignId String`
- `referrerUserId String`
- `referredUserId String @unique`
- `referralCode String`
- `status String @default("valid")` — valid, invalid, self_referral
- `createdAt DateTime @default(now())`
- `campaign Campaign @relation(fields:[campaignId], references:[id])`
- `referrer User @relation("ReferrerReferrals", fields:[referrerUserId], references:[id])`
- `referred User @relation("ReferredReferrals", fields:[referredUserId], references:[id])`
- `@@index([campaignId])`
- `@@index([referrerUserId])`
- `@@index([referralCode])`
- `@@index([status])`

Model `AdminUser`:
- `id String @id @default(uuid())`
- `email String @unique`
- `passwordHash String`
- `role String @default("operator")`
- `createdAt DateTime @default(now())`
</action>

<action>
