# Plan 04-02: Public Campus & Referrer Leaderboard Endpoints

## Goal
Implement privacy-respecting public leaderboard endpoints for campus rankings and top student referrers, using efficient SQL queries with deterministic tie-breaking.

## Tasks

<task id="04-02-01">
<title>Implement campus leaderboard service with privacy protection</title>
<action>
Create `backend/src/services/leaderboard.service.ts`:

Export `getCampusLeaderboard(campaignId: string, limit = 50): Promise<CampusLeaderboardItem[]>`:

Use `prisma.$queryRaw` with parameterized Prisma.sql template (prevents injection):
```sql
SELECT
  c.id as "collegeId",
  c.name as "collegeName",
  c.city,
  c.state,
  COUNT(u.id)::int as "registrations",
  ROW_NUMBER() OVER (ORDER BY COUNT(u.id) DESC, c.name ASC) as rank
FROM "College" c
INNER JOIN "User" u ON u."collegeId" = c.id
WHERE u."campaignId" = ${campaignId}
GROUP BY c.id, c.name, c.city, c.state
ORDER BY "registrations" DESC, c.name ASC
LIMIT ${limit}
```

Return array of `CampusLeaderboardItem`:
- `rank: number`, `collegeId: string`, `collegeName: string`, `city: string`, `state: string`, `registrations: number`
- NEVER include email, phone, or user IDs

Export `getRegistrationCount(campaignId: string): Promise<number>`:
- `prisma.user.count({ where: { campaignId } })`

Export interface `CampusLeaderboardItem { rank: number; collegeId: string; collegeName: string; city?: string; state?: string; registrations: number }`
</action>

<task id="04-02-02">
<title>Implement referrer leaderboard and wire all leaderboard routes</title>
<action>
Add to `backend/src/services/leaderboard.service.ts`:

Export `getReferrerLeaderboard(campaignId: string, limit = 50): Promise<ReferrerLeaderboardItem[]>`:

Use `prisma.$queryRaw`:
```sql
SELECT
  u.id as "userId",
  u."fullName",
  c.name as "collegeName",
  COUNT(r.id)::int as "referralCount",
  ROW_NUMBER() OVER (ORDER BY COUNT(r.id) DESC, u."createdAt" ASC) as rank
FROM "User" u
INNER JOIN "College" c ON c.id = u."collegeId"
LEFT JOIN "Referral" r ON r."referrerUserId" = u.id AND r.status = 'valid'
WHERE u."campaignId" = ${campaignId}
GROUP BY u.id, u."fullName", c.name, u."createdAt"
HAVING COUNT(r.id) > 0
ORDER BY "referralCount" DESC, u."createdAt" ASC
LIMIT ${limit}
```

Return `ReferrerLeaderboardItem`:
- `rank: number`, `userId: string`, `fullName: string`, `collegeName: string`, `referralCount: number`
- NO email, NO phone — NEVER

Create `backend/src/controllers/leaderboard.controller.ts`:
- Export `campusLeaderboardHandler(req, res, next)`: reads `?campaignId` param (if absent, fetches active campaign id), calls `getCampusLeaderboard`, returns `{ items, total: registrationCount }`
- Export `referrerLeaderboardHandler(req, res, next)`: same pattern, calls `getReferrerLeaderboard`, returns `{ items }`

Create `backend/src/routes/leaderboard.ts`:
- `GET /campuses` → `[leaderboardRateLimiter, campusLeaderboardHandler]`
- `GET /referrers` → `[leaderboardRateLimiter, referrerLeaderboardHandler]`

Mount in `backend/src/app.ts` at `/api/v1/leaderboard`.
</action>
