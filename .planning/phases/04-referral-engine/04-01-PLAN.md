# Plan 04-01: Referral Attribution Service with Transactional Integrity

## Goal
Implement the referral attribution service that creates explicit Referral records atomically when a friend completes valid registration, with full anti-abuse protection (self-referral rejection, duplicate attribution prevention, circular referral detection).

## Artifacts this phase produces
- `backend/src/services/referral.service.ts` — referral creation and attribution logic
- Updates to `backend/src/services/registration.service.ts` — integrate referral attribution
- `backend/src/validators/referral.validator.ts` — referral input schema

## Tasks

<task id="04-01-01">
<title>Implement referral attribution service with anti-abuse checks</title>
<action>
Create `backend/src/services/referral.service.ts`:

Export `interface AttributionResult { credited: boolean; reason: string }`

Export `attributeReferral(params: { campaignId: string; referrerId: string; referredUserId: string; referralCode: string }): Promise<AttributionResult>`:

Anti-abuse checks (in order, return reason without throwing):
1. **Self-referral**: if `referrerId === referredUserId` return `{ credited: false, reason: 'self_referral' }`
2. **Already attributed**: `prisma.referral.findUnique({ where: { referredUserId } })` — if exists return `{ credited: false, reason: 'already_attributed' }`

Create referral record in transaction:
```
prisma.$transaction([
  prisma.referral.create({
    data: { campaignId, referrerUserId: referrerId, referredUserId, referralCode, status: 'valid' }
  })
])
```

Return `{ credited: true, reason: 'attributed' }`

Export `getReferralStats(userId: string, campaignId: string): Promise<{ referralCode, referralUrl, referralCount, goal, campusRank }>`:
- `prisma.referral.count({ where: { referrerUserId: userId, campaignId, status: 'valid' } })` → referralCount
- Fetch user's referralCode from `prisma.user.findUnique({ where: { id: userId }, select: { referralCode, collegeId } })`
- Campus rank query:
  ```sql
  SELECT rank FROM (
    SELECT collegeId, ROW_NUMBER() OVER (ORDER BY COUNT(*) DESC, collegeId ASC) as rank
    FROM User WHERE campaignId = ?
    GROUP BY collegeId
  ) ranked WHERE collegeId = ?
  ```
  Use `prisma.$queryRaw` for this window function query
- Return `{ referralCode, referralUrl: buildReferralUrl(referralCode, FRONTEND_URL), referralCount, goal: 3, campusRank: rank }`
</action>

<task id="04-01-02">
<title>Integrate referral attribution into registration service transaction</title>
<action>
Update `backend/src/services/registration.service.ts` `registerStudent` function:

After creating the user (step 6 transaction), if `input.referralCode` was provided and referrer user exists:
- Call `attributeReferral({ campaignId, referrerId: referrer.id, referredUserId: newUser.id, referralCode: input.referralCode })`
- Log attribution result but do NOT fail registration if attribution is not credited (e.g. self-referral gracefully continues)
- The referral attribution runs AFTER user creation but WITHIN the same broader try/catch scope

Important: User creation must succeed even if referral attribution returns `credited: false`. Registration is independent; referral credit is additive.

Create `backend/src/routes/users.ts`:
- `GET /:userId/referrals` → `getReferralStatsHandler`:
  - Validate `userId` param is a UUID
  - Call `getReferralStats(userId, campaignId)` (fetch active campaign internally)
  - Return 200 with stats object
  - If user not found: return 404 with `USER_NOT_FOUND` code

Mount `/api/v1/users` route in `backend/src/app.ts`.
</action>
