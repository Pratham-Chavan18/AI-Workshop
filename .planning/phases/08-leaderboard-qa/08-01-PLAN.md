<title>Build Admin Analytics Dashboard with KPI cards and charts</title>
<action>
Create `frontend/src/components/admin/kpi-cards.tsx`:
4 KPI metric cards using `Card` component:
1. Total Registrations — large number + "/ 500 goal" subtext
2. Goal Progress — circular or linear progress `{goalProgress}%`
3. Referral Rate — `{referralRate}%` of registrations came via referral
4. Active Campuses — count of colleges with at least 1 registration

Each card: animated count-up using Framer Motion on mount.

Create `frontend/src/components/admin/registration-chart.tsx`:
Daily trend bar chart using `recharts` (add to `frontend/package.json` dependencies):
- Fetch `GET /api/v1/admin/campaigns/:id/stats/daily` with admin key header
- Bar chart with date on X-axis, count on Y-axis
- Primary blue (#0064e0) bars
- Responsive container adapting to viewport width

Create `frontend/src/components/admin/referral-source-table.tsx`:
- Fetch `/api/v1/admin/campaigns/:id/stats/sources`
- Simple table: Source | Count | %
- Sources: whatsapp, direct, other

Create `frontend/src/components/admin/ambassador-table.tsx`:
- Reuse leaderboard referrers data (fetch `GET /api/v1/leaderboard/referrers`)
- Table: Rank | Name | Campus | Referrals

Create `frontend/src/pages/AdminPage.tsx`:
- Document title: "Admin Dashboard | AI 60×500"

- Add `recharts` to `frontend/package.json`: `"recharts": "^2.12.0"`
