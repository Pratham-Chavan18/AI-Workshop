## Tasks

<task id="03-02-01">
<title>Implement referral code generator utility</title>
<action>
Create `backend/src/utils/referralCode.ts`:

Export `generateReferralCode(maxAttempts = 10): Promise<string>`:
- Character set: `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (no ambiguous chars: O, 0, I, 1)
- Length: 6 characters
- Generate random code using `crypto.randomBytes` (NOT Math.random for security)
- Loop up to `maxAttempts` checking uniqueness with `prisma.user.findUnique({ where: { referralCode } })`
- If unique: return code
- If all attempts collide: throw `Error('Could not generate unique referral code')`

Export `buildReferralUrl(code: string, baseUrl: string): string`:
- Returns `${baseUrl}/register?ref=${code}`
</action>

<task id="03-02-02">
<title>Implement registration service with duplicate detection and campaign validation</title>
<action>
Create `backend/src/services/registration.service.ts`:

Export `interface RegisterResult { user: { id, fullName, referralCode, referralUrl }; isNew: boolean }`

Export `registerStudent(input: RegistrationInput): Promise<RegisterResult>`:

1. **Fetch active campaign**:
   - `prisma.campaign.findFirst({ where: { status: 'active' } })`
   - If none found: throw AppError with code `CAMPAIGN_CLOSED` and HTTP 422

2. **Validate college**:
   - `prisma.college.findUnique({ where: { id: input.collegeId } })`
   - If not found: throw AppError with code `VALIDATION_ERROR` message `'Invalid college ID'` HTTP 400

3. **Validate referral code** (if provided):
   - `prisma.user.findUnique({ where: { referralCode: input.referralCode } })`
   - If not found: throw AppError with code `INVALID_REFERRAL_CODE` HTTP 400

4. **Check for duplicate email**:
   - `prisma.user.findFirst({ where: { campaignId, emailNormalized: input.email.toLowerCase().trim() } })`
   - If found: throw AppError with code `EMAIL_ALREADY_REGISTERED` HTTP 409

5. **Generate referral code**: call `generateReferralCode()`

6. **Create user in transaction**:
   - `prisma.$transaction(async (tx) => {`
   - `tx.user.create({ data: { campaignId, collegeId, fullName, email, emailNormalized, phone, phoneNormalized, graduationYear, referralCode, referredByUserId: referrer?.id || null, source } })`
   - Return user record
   - `})`

7. Return `{ user: { id, fullName, referralCode, referralUrl: buildReferralUrl(referralCode, FRONTEND_URL) }, isNew: true }`

Create `backend/src/utils/errors.ts`:
- Export `class AppError extends Error { statusCode: number; code: string }`
- Export error factory functions: `campaignClosed()`, `emailAlreadyRegistered()`, `invalidReferralCode()`, `selfReferral()`, `validationError(msg)`

Update `backend/src/middleware/errorHandler.ts` to handle `AppError` instances by returning their `statusCode` and structured `{ success: false, error: { code, message } }`.
</action>
