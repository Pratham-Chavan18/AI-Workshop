## Tasks

<task id="03-01-01">
<title>Implement GET /api/v1/colleges search endpoint</title>
<action>
Create `backend/src/services/colleges.service.ts`:
- Export `searchColleges(query: string, limit = 20)`:
  - Use `prisma.college.findMany` with `where: { nameNormalized: { contains: query.toLowerCase().trim() } }`
  - `orderBy: { name: 'asc' }`
  - `take: limit`
  - Return `{ id, name, city, state }` (no createdAt)

Create `backend/src/controllers/colleges.controller.ts`:
- Export `searchCollegesHandler(req, res, next)`:
  - Read `?search` query param, default empty string
  - If `search` length < 1 return `{ items: [] }` with 200
  - Call `searchColleges(search)`
  - Return `{ items: results }` with 200
  - Wrap in try/catch, forward errors to next()

Create `backend/src/routes/colleges.ts`:
- `GET /` → `searchCollegesHandler`

Mount in `backend/src/app.ts` at `/api/v1/colleges`.
</action>

<task id="03-01-02">
<title>Create registration Zod validator with normalization</title>
<action>
Create `backend/src/validators/registration.validator.ts`:

Export `registrationSchema` using `z.object()`:
- `fullName`: `z.string().min(2).max(100).trim()`
- `email`: `z.string().email().toLowerCase().trim()` — normalized lowercase
- `phone`: `z.string().regex(/^\+?[1-9]\d{9,14}$/).optional().nullable()` — E.164-compatible
- `collegeId`: `z.string().uuid()` — must be valid UUID
- `graduationYear`: `z.number().int().min(2024).max(2028)`
- `referralCode`: `z.string().regex(/^[A-Z0-9]{6,8}$/).optional().nullable()` — uppercase alphanumeric
- `source`: `z.enum(['whatsapp', 'direct', 'other']).default('direct')`

Export `RegistrationInput` type inferred from schema.

Export `normalizeRegistration(data: RegistrationInput)`:
- Returns `{ ...data, emailNormalized: data.email.toLowerCase().trim(), phoneNormalized: data.phone?.replace(/\s+/g, '') || null }`

Create `backend/src/middleware/validate.ts`:
- Export generic `validate(schema: ZodSchema)` middleware factory
- Parse `req.body` with `schema.safeParse`
- On failure: return 400 with `{ success: false, error: { code: 'VALIDATION_ERROR', message: 'Validation failed', details: zodError.flatten().fieldErrors } }`
- On success: set `req.body = parsed.data` and call `next()`
</action>

<task id="03-01-03">
<title>Create rate limiter middleware for registration endpoint</title>
<action>
Create `backend/src/middleware/rateLimiter.ts`:
- Import `rateLimit` from `express-rate-limit`

Export `registrationRateLimiter = rateLimit({`:
- `windowMs: 15 * 60 * 1000` (15 minutes)
- `max: 10` (10 registration attempts per IP per window)

- `max: 60` (60 requests per minute for public leaderboard)
