# Plan 05-01: Admin Authentication Middleware & Campaign Analytics Service

## Goal
Implement secure `X-Admin-Key` header authentication middleware and admin analytics service providing campaign KPIs: total registrations, goal progress, referral rate, active campuses, top referrers, and daily registration trends.

## Artifacts this phase produces
- `backend/src/middleware/adminAuth.ts`
- `backend/src/services/admin.service.ts`
- `backend/src/controllers/admin.controller.ts` (stats + trends handlers)
- `backend/src/routes/admin.ts`

## Tasks

<task id="05-01-01">
<title>Implement X-Admin-Key authentication middleware</title>
<action>
Create `backend/src/middleware/adminAuth.ts`:

Export `requireAdminKey(req, res, next)`:
- Read header `req.headers['x-admin-key']`
- Compare against `process.env.ADMIN_API_KEY` using `crypto.timingSafeEqual(Buffer.from(provided), Buffer.from(expected))` to prevent timing attacks
- If header missing: return HTTP 401 `{ success: false, error: { code: 'UNAUTHORIZED', message: 'Admin authentication required' } }`
- If mismatch: return HTTP 403 `{ success: false, error: { code: 'FORBIDDEN', message: 'Invalid admin key' } }`
- If `process.env.ADMIN_API_KEY` is not set in env: log error and return 503

Also add a strict admin rate limiter in `backend/src/middleware/rateLimiter.ts`:
- Export `adminRateLimiter = rateLimit({ windowMs: 60 * 1000, max: 30, ... })` for admin endpoints
</action>

<task id="05-01-02">
<title>Implement campaign analytics service and stats endpoint</title>
<action>
Create `backend/src/services/admin.service.ts`:

Export `getCampaignStats(campaignId: string)`:
Use `prisma.$transaction` to batch:
1. `prisma.user.count({ where: { campaignId } })` → `totalRegistrations`
2. `prisma.referral.count({ where: { campaignId, status: 'valid' } })` → `referralRegistrations`
3. `prisma.user.groupBy({ by: ['collegeId'], where: { campaignId }, _count: { id: true } })`.length → `activeCampuses`
4. Fetch campaign `targetRegistrations` (500)

Compute:
- `goalProgress = Math.round((totalRegistrations / targetRegistrations) * 100)`
- `referralRate = totalRegistrations > 0 ? Math.round((referralRegistrations / totalRegistrations) * 100 * 100) / 100 : 0`

Return `{ target: 500, registrations: totalRegistrations, referralRegistrations, activeCampuses, referralRate, goalProgress }`

Export `getDailyRegistrationTrend(campaignId: string, days = 7)`:
Use `prisma.$queryRaw` to group registrations by day:
```sql
SELECT DATE("createdAt" AT TIME ZONE 'Asia/Kolkata') as date, COUNT(*)::int as count
FROM "User"
WHERE "campaignId" = ${campaignId}
  AND "createdAt" >= NOW() - INTERVAL '${days} days'
GROUP BY DATE("createdAt" AT TIME ZONE 'Asia/Kolkata')
ORDER BY date ASC
```
Return `{ date: string; count: number }[]`

Export `getSourceBreakdown(campaignId: string)`:
- `prisma.user.groupBy({ by: ['source'], where: { campaignId }, _count: { id: true } })`
- Return `{ source: string; count: number }[]`

Create `backend/src/controllers/admin.controller.ts`:
- Export `campaignStatsHandler` — calls `getCampaignStats`, returns 200 with stats
- Export `dailyTrendHandler` — calls `getDailyRegistrationTrend`, returns 200 with trend array
- Export `sourceBreakdownHandler` — calls `getSourceBreakdown`, returns 200 with sources array
</action>

## Verification

```bash
# Without auth
curl "http://localhost:4000/api/v1/admin/campaigns/CAMP_ID/stats"
# HTTP 401: { "success": false, "error": { "code": "UNAUTHORIZED" } }

# With correct auth (using configured ADMIN_API_KEY environment variable)
curl -H "X-Admin-Key: $ADMIN_API_KEY" \
  "http://localhost:4000/api/v1/admin/campaigns/CAMP_ID/stats"
# HTTP 200: { "target": 500, "registrations": N, "referralRegistrations": N, "activeCampuses": N, ... }

# With invalid auth
curl -H "X-Admin-Key: $INVALID_KEY" \
  "http://localhost:4000/api/v1/admin/campaigns/CAMP_ID/stats"
# HTTP 403: { "success": false, "error": { "code": "FORBIDDEN" } }
```
