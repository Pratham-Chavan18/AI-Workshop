# Plan 05-02: Registration Data Export Endpoint (CSV & JSON)

## Goal
Implement the authorized streaming data export endpoint that produces complete verified registration records for campaign operators in both CSV and JSON formats, with proper privacy controls ensuring only non-sensitive operational fields are exported.

## Artifacts this phase produces
- Updates to `backend/src/services/admin.service.ts` — export query
- Updates to `backend/src/controllers/admin.controller.ts` — export handler
- Updates to `backend/src/routes/admin.ts` — export route (replacing stub)

## Tasks

<task id="05-02-01">
<title>Implement registration export service with field selection</title>
<action>
Add to `backend/src/services/admin.service.ts`:

Export `getExportData(campaignId: string)`:
- `prisma.user.findMany({`
- `where: { campaignId },`
- `select: {`
  - `id: true`
  - `fullName: true`
  - `email: true`
  - `phone: true`
  - `graduationYear: true`
  - `source: true`
  - `createdAt: true`
  - `referralCode: true`
  - `referredByUserId: true`
  - `college: { select: { name: true, city: true, state: true } }`
  - `referralsMade: { select: { id: true }, where: { status: 'valid' } }`
- `},`
- `orderBy: { createdAt: 'asc' }`
- `})`

Map results to flat export object:
```
{
  id, fullName, email, phone: phone || '',
  collegeName: college.name, collegeCity: college.city, collegeState: college.state,
  graduationYear, referralCode, referredByUserId: referredByUserId || '',
  referralsMadeCount: referralsMade.length,
  source, registeredAt: createdAt.toISOString()
}
```

Note: Export includes email and phone ONLY for authorized admin operators (not on public endpoints).
</action>

<task id="05-02-02">
<title>Implement streaming CSV export controller with format negotiation</title>
<action>
Add to `backend/src/controllers/admin.controller.ts`:

Export `exportRegistrationsHandler(req, res, next)`:
- Read `?format=csv` or `?format=json` query param (default: csv)
- Read `campaignId` from route params, verify campaign exists
- Call `getExportData(campaignId)`

If format is `csv`:
- Set headers: `Content-Type: text/csv; charset=utf-8`, `Content-Disposition: attachment; filename="ai60-registrations-${Date.now()}.csv"`
- Build CSV manually:
  - Header row: `id,fullName,email,phone,collegeName,collegeCity,collegeState,graduationYear,referralCode,referredByUserId,referralsMadeCount,source,registeredAt`
  - Data rows: escape commas and quotes in values (`"` → `""`)
  - Use `res.write()` for each row (streaming)
- Call `res.end()`

If format is `json`:
- Set `Content-Type: application/json`
- Set `Content-Disposition: attachment; filename="ai60-registrations-${Date.now()}.json"`
- Return `res.json({ count: data.length, data })`

Update `backend/src/routes/admin.ts`:
- Replace stub `GET /campaigns/:campaignId/export` with `exportRegistrationsHandler`
</action>
