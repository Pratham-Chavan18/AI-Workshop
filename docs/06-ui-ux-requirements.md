# UI/UX Requirements

## Design Direction
Modern, student-focused, high-energy but credible. Prioritize mobile because WhatsApp sharing will be a major acquisition mechanism.

## Screen 1 — Landing Page

### Hero
Headline:
**Build Your First AI Project in 60 Minutes**

Supporting line:
**One hour. One real project. Zero cost.**

CTA:
**Reserve My Free Seat**

### Sections
1. What you will build
2. Who should join
3. 60-minute workshop agenda
4. What you take away
5. Social proof / number of registrations
6. Campus challenge
7. Final CTA

## Screen 2 — Registration
Fields:
- Full name
- Email
- Phone (optional unless verification is enabled)
- College
- Graduation year

If URL contains `?ref=CODE`, preserve that code during submission.

## Screen 3 — Success / Referral Dashboard
Show:
- Registration confirmed
- Referral code
- Copy referral link
- WhatsApp share CTA
- Referral progress `0/3`
- Campus name
- Campus rank

## Screen 4 — Campus Leaderboard
Show:
- Rank
- College
- Valid registrations

Do not expose private student data.

Optional second tab:
**Top Student Referrers**

## Screen 5 — Admin Dashboard
Cards:
- Total registrations
- Goal progress
- Referral registrations
- Active campuses
- Conversion rate

Charts:
- Registrations by day
- Registrations by source
- Top campuses
- Top referrers

## UX Principles
- One main CTA per section
- Avoid long forms
- Use clear success states
- Optimize for mobile
- Make sharing one click
- Never require students to understand referral mechanics before registering
